# UC-018: Funding & Grants Landscape

- **Domain:** research / finance · **Difficulty:** intermediate · **Time:** 30–60 min

## Goal
Map funding sources available to a project: grants, subsidies, accelerators, investors.

## Inputs
Project description; geography; stage; funding need.

## Steps
1. Generate candidate sources grouped by type: public grants, subsidies, accelerators, angels, VCs.
2. Per source: eligibility, amount range, deadline, application effort, success signals.
3. Match to project profile; shortlist by fit and deadline.
4. Note stacking rules — which sources combine.

## Verification
Each program verified against its official page; deadlines must be confirmed for the current cycle.

## Expected Output
Funding map + shortlist with deadlines + application order.

## Variations
R&D tax credits · non-dilutive first strategy.
