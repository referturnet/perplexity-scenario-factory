# UC-014: Expert & Thought-Leader Discovery

- **Domain:** research / network · **Difficulty:** basic · **Time:** 20–40 min

## Goal
Find the people worth interviewing, following, or citing in a domain.

## Inputs
Domain description; context (hiring, expert network, content).

## Steps
1. Generate candidate list from talks, papers, posts, open-source work.
2. For each candidate: affiliation, recent work, channels, contact surface.
3. Cluster by sub-topic; flag bridging figures connecting clusters.
4. Rank by signal quality (primary work vs. commentary).

## Verification
Each person must have a verifiable recent artifact (talk, paper, repo, post) with link.

## Expected Output
Ranked expert table grouped by sub-topic + outreach notes.

## Variations
Advisory-board sourcing · podcast guest shortlist.
