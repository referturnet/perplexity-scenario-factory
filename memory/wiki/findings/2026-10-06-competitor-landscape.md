# Competitor Landscape — Prompt & Scenario Libraries

- **Date:** 2026-10-06
- **Iteration:** 1 (market research cycle)
- **Method:** Web research across GitHub, prompt-library directories, and official vendor hubs
- **Scope:** Direct and adjacent competitors for perplexity-scenario-factory

## Summary

The prompt-library market is dominated by one giant (f/awesome-chatgpt-prompts, ~134k+ stars), but it is generic and model-agnostic. The Perplexity-specific niche is nearly empty: the closest direct competitor (labeldekho/perplexity-prompts-guide, 87 stars) is a static guide with no scenarios, no agent instructions, and no project memory. Our positioning — 200 executable scenarios + LLM-Wiki project memory + multi-agent instructions (Claude Code / Codex / Cursor / Windsurf) — has no direct equivalent found in this research pass.

## Positioning Statement

perplexity-scenario-factory is not another prompt list. It is a scenario factory: 200 structured use cases for Perplexity browser automation, a deep-research system, LLM-Wiki project memory, and agent instructions for multiple coding agents. Differentiators to emphasize in all marketing: (1) executable scenarios vs. copy-paste prompts, (2) persistent project memory (LLM-Wiki), (3) multi-agent portability, (4) 200-case catalog depth in a near-empty niche.

## Threats

- Awesome-list giants absorb generic search traffic; we cannot win on generic keywords.
- Perplexity itself may publish an official scenario library (their use-cases hub is a precedent).
- Prompt marketplaces have distribution we lack.

- → backlog/marketing-2026Q4.md (phased marketing roadmap, this iteration)
- → Prioritize keywords around 'perplexity automation', 'perplexity scenarios', 'deep research workflows', 'agent instructions' rather than generic 'prompts'.
